# Region: graphics

## `graphics.line`

- args: `x1= y1= x2= y2=`
- returns: str
- example: `graphics.line x1=0 y1=0 x2=40 y2=0`
- draw a graphic line (NOT electrical)

## `graphics.rect`

- args: `x1= y1= x2= y2=`
- returns: str
- example: `graphics.rect x1=0 y1=0 x2=40 y2=40`
- draw a rectangle

## `graphics.text`

- args: `x= y= text=`
- returns: str
- example: `graphics.text x=10 y=10 text=hi`
- draw text
